## 一、项目概述

### 1.1 项目简介

**阅小师**是一款面向大学物理教学的智能AI批改系统，支持教师布置作业、AI自动批改、学情分析，以及学生在线答题、错题复习等功能。

### 1.2 用户角色

| 角色 | 权限 | 功能 |
|------|------|------|
| **教师** | TEACHER | 班级管理、题库管理、作业布置、阅卷批改、学情分析 |
| **学生** | STUDENT | 完成作业、查看错题、学习报告、复习模式 |
| **管理员** | ADMIN | 系统配置、用户管理、数据监控 |

### 3.2 数据表详细设计

#### 3.2.1 用户表 (users)

```sql
-- 用户基础信息表
CREATE TABLE `users` (
    `id`              BIGINT UNSIGNED     NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `email`           VARCHAR(100)        NOT NULL COMMENT '邮箱（登录账号）',
    `password`        VARCHAR(255)        NOT NULL COMMENT '加密密码（BCrypt）',
    `name`            VARCHAR(50)         NOT NULL COMMENT '用户姓名',
    `role`            ENUM('teacher','student','admin') NOT NULL COMMENT '角色',
    `avatar`          VARCHAR(500)        NULL COMMENT '头像URL',
    `phone`           VARCHAR(20)         NULL COMMENT '手机号',
    `status`          TINYINT             DEFAULT 1 COMMENT '状态：0-禁用 1-启用',
    `last_login_at`   DATETIME            NULL COMMENT '最后登录时间',
    `created_at`      DATETIME            DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`      DATETIME            DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `deleted`         TINYINT             DEFAULT 0 COMMENT '软删除标记',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_email` (`email`),
    KEY `idx_role` (`role`),
    KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```


### 4.1 接口基础规范

#### 4.1.1 基础信息

| 项目 | 值 |
|------|-----|
| **基础URL** | `http://localhost:8080/api` |
| **协议** | HTTP/HTTPS |
| **数据格式** | JSON |
| **字符编码** | UTF-8 |
| **认证方式** | JWT Bearer Token |

#### 4.1.2 统一响应格式

**成功响应 (HTTP 200)**:
```json
{
  "success": true,
  "data": { ... },
  "message": "操作成功",
  "timestamp": "2026-05-02T14:30:00Z"
}
```

**错误响应 (HTTP 4xx/5xx)**:
```json
{
  "success": false,
  "error": {
    "code": "ERR_001",
    "message": "错误描述",
    "details": { ... }
  },
  "timestamp": "2026-05-02T14:30:00Z"
}
```

#### 4.1.3 HTTP状态码

| 状态码 | 含义 | 使用场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 资源创建成功 |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证/Token无效 |
| 403 | Forbidden | 无权限访问 |
| 404 | Not Found | 资源不存在 |
| 409 | Conflict | 资源冲突（如重复） |
| 422 | Unprocessable | 业务逻辑错误 |
| 500 | Server Error | 服务器内部错误 |

## 五、业务逻辑详解

### 5.1 作业提交流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   学生提交   │────▶│  验证作业   │────▶│  保存答案   │────▶│  触发批改   │
│   作业      │     │  状态/时间   │     │  到数据库   │     │  任务      │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                    │
                    ┌─────────────┐     ┌─────────────┐            │
                    │  更新错题本  │◀────│  保存批改   │◀───────────┘
                    │  (自动添加)  │     │  结果      │
                    └─────────────┘     └─────────────┘
```

**详细流程**:
1. 学生提交作业答案
2. 系统验证：
   - 作业是否存在且处于active状态
   - 是否在截止时间前（或允许逾期）
   - 学生是否属于该班级
3. 保存提交记录到submissions表
4. 如果grading_type为AI，发送消息到RabbitMQ队列
5. AI服务消费消息，进行批改
6. 保存每道题的批改详情到grade_details表
7. 自动将错题添加到error_books表
8. 发送通知给学生

### 5.2 AI批改流程

```java
@Service
public class AIGradingService {
    
    @Autowired
    private AIServiceClient aiClient;
    
    @Autowired
    private SubmissionMapper submissionMapper;
    
    @Autowired
    private GradeDetailMapper gradeDetailMapper;
    
    @Autowired
    private ErrorBookService errorBookService;
    
    @RabbitListener(queues = "ai.grading.queue")
    public void handleGradingTask(GradingTask task) {
        // 1. 获取作业和题目信息
        Assignment assignment = assignmentMapper.selectById(task.getAssignmentId());
        List<Question> questions = questionMapper.selectBatchIds(assignment.getQuestionIds());
        Submission submission = submissionMapper.selectById(task.getSubmissionId());
        
        // 2. 逐题批改
        int totalScore = 0;
        List<GradeDetail> details = new ArrayList<>();
        
        for (Question question : questions) {
            String studentAnswer = submission.getAnswers().get(String.valueOf(question.getId()));
            
            // 调用AI服务批改
            AIGradingResult result = aiClient.gradeQuestion(
                question.getContent(),
                question.getAnswer(),
                studentAnswer
            );
            
            // 保存批改详情
            GradeDetail detail = new GradeDetail();
            detail.setSubmissionId(submission.getId());
            detail.setQuestionId(question.getId());
            detail.setStudentAnswer(studentAnswer);
            detail.setScore(result.getScore());
            detail.setFullScore(question.getFullScore());
            detail.setIsCorrect(result.getScore() >= question.getFullScore() * 0.6);
            detail.setAiFeedback(JSON.toJSONString(result.getFeedback()));
            detail.setErrorTypes(JSON.toJSONString(result.getErrorTypes()));
            
            gradeDetailMapper.insert(detail);
            details.add(detail);
            totalScore += result.getScore();
            
            // 3. 如果是错题，添加到错题本
            if (!detail.getIsCorrect()) {
                errorBookService.addError(
                    submission.getStudentId(),
                    question.getId(),
                    submission.getId(),
                    result.getErrorTypes().get(0),
                    studentAnswer,
                    question.getAnswer().getResult()
                );
            }
        }
        
        // 4. 更新提交记录
        submission.setStatus("graded");
        submission.setTotalScore(totalScore);
        submission.setAiScore(totalScore);
        submission.setAiFeedback(JSON.toJSONString(buildFeedback(details)));
        submission.setGradedAt(LocalDateTime.now());
        submissionMapper.updateById(submission);
        
        // 5. 发送通知
        notificationService.sendGradingCompleteNotification(submission);
    }
}
```

### 5.3 学情分析计算逻辑

#### 5.3.1 知识点掌握度计算

```java
@Service
public class AnalyticsService {
    
    /**
     * 计算学生知识点掌握度
     * 掌握度 = (正确次数 / 总尝试次数) * 100
     * 权重：近期答题权重更高
     */
    public int calculateMastery(Long studentId, String knowledgePoint) {
        List<GradeDetail> details = gradeDetailMapper
            .selectByStudentAndKnowledgePoint(studentId, knowledgePoint);
        
        if (details.isEmpty()) {
            return 0;
        }
        
        double weightedScore = 0;
        double totalWeight = 0;
        
        for (int i = 0; i < details.size(); i++) {
            GradeDetail detail = details.get(i);
            // 时间权重：越新的记录权重越高
            double timeWeight = Math.pow(1.1, i);
            double accuracy = detail.getIsCorrect() ? 1.0 : 0.0;
            
            weightedScore += accuracy * timeWeight;
            totalWeight += timeWeight;
        }
        
        return (int) Math.round((weightedScore / totalWeight) * 100);
    }
    
    /**
     * 计算班级平均分
     */
    public double calculateClassAverage(Long classId, String chapter) {
        return submissionMapper.selectClassAverage(classId, chapter);
    }
    
    /**
     * 生成AI教学洞察
     */
    public List<AIInsight> generateInsights(Long classId) {
        List<AIInsight> insights = new ArrayList<>();
        
        // 1. 检查各章节掌握度
        List<ChapterStat> chapterStats = analyticsMapper
            .selectChapterStats(classId);
        
        for (ChapterStat stat : chapterStats) {
            if (stat.getMasteryRate() < 0.6) {
                insights.add(AIInsight.builder()
                    .type("warning")
                    .title(stat.getChapterName() + "章节薄弱")
                    .content(String.format(
                        "班级在%s章节掌握度仅为%.0f%%，建议加强练习",
                        stat.getChapterName(),
                        stat.getMasteryRate() * 100
                    ))
                    .affectedStudents(stat.getLowScoreCount())
                    .suggestions(Arrays.asList(
                        "增加课后练习",
                        "组织专题讲解",
                        "推荐相关视频"
                    ))
                    .build());
            }
        }
        
        // 2. 检查进步趋势
        TrendAnalysis trend = analyticsMapper.selectTrendAnalysis(classId);
        if (trend.getImprovement() > 10) {
            insights.add(AIInsight.builder()
                .type("success")
                .title(trend.getChapterName() + "进步明显")
                .content(String.format(
                    "相比上月，班级%s平均分提升%.0f分",
                    trend.getChapterName(),
                    trend.getImprovement()
                ))
                .improvement(trend.getImprovement())
                .build());
        }
        
        return insights;
    }
}
```

### 5.4 错题本管理逻辑

```java
@Service
public class ErrorBookService {
    
    /**
     * 添加错题
     */
    @Transactional
    public void addError(Long studentId, Long questionId, Long submissionId,
                        String errorType, String studentAnswer, String correctAnswer) {
        // 检查是否已存在
        ErrorBook existing = errorBookMapper
            .selectByStudentAndQuestion(studentId, questionId);
        
        if (existing != null) {
            // 更新错误次数
            existing.setErrorCount(existing.getErrorCount() + 1);
            existing.setErrorType(errorType);
            existing.setStudentAnswer(studentAnswer);
            existing.setIsMastered(false);
            errorBookMapper.updateById(existing);
        } else {
            // 新增错题记录
            ErrorBook error = new ErrorBook();
            error.setStudentId(studentId);
            error.setQuestionId(questionId);
            error.setSubmissionId(submissionId);
            error.setErrorType(errorType);
            error.setErrorCount(1);
            error.setStudentAnswer(studentAnswer);
            error.setCorrectAnswer(correctAnswer);
            error.setIsMastered(false);
            errorBookMapper.insert(error);
        }
    }
    
    /**
     * 标记错题已复习
     */
    @Transactional
    public void markAsReviewed(Long errorId, boolean isCorrect) {
        ErrorBook error = errorBookMapper.selectById(errorId);
        if (error == null) {
            throw new BusinessException("错题记录不存在");
        }
        
        error.setReviewCount(error.getReviewCount() + 1);
        error.setLastReviewedAt(LocalDateTime.now());
        
        // 如果连续答对3次，标记为已掌握
        if (isCorrect && error.getReviewCount() >= 3) {
            error.setIsMastered(true);
        }
        
        errorBookMapper.updateById(error);
    }
    
    /**
     * 获取AI推荐练习
     */
    public List<Question> getRecommendedPractice(Long errorId) {
        ErrorBook error = errorBookMapper.selectById(errorId);
        Question question = questionMapper.selectById(error.getQuestionId());
        
        // 调用AI服务获取推荐
        return aiClient.getSimilarQuestions(
            question.getChapter(),
            question.getKnowledgePoints(),
            question.getDifficulty(),
            5  // 推荐5道相似题
        );
    }
```
